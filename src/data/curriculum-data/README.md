# Zocesh Study AI Curriculum Database

This directory contains the structured curriculum used by Zocesh Study AI.

Classes:
- JSS1
- JSS2
- JSS3
- SS1
- SS2
- SS3

Each class can contain multiple curriculum/examination pathways.

Curriculum sources must be based on authoritative sources such as:
- NERDC
- WAEC
- NECO
- JAMB
- Lagos State/BECE authorities where applicable

Do not replace verified curriculum content with invented topics.

Each subject should eventually contain:
- topics
- subtopics
- learning objectives
- explanations
- formulas where applicable
- practical requirements where applicable
- common mistakes
- examination relevance
- recommended study time
- curriculum version
- source/reference metadata
